# SkillBarter (Next.js + Tailwind макет)

Только фронтенд: без базы данных и сервера. Данные лежат в `components/data.js`.

## Запуск
1. Установите Node.js 18.18+ (https://nodejs.org)
2. В терминале VS Code (Ctrl+`):
   npm install
   npm run dev
3. Откройте http://localhost:3000

## Страницы
- `/`          — Главная (app/page.js)
- `/find`      — Найти помощь (app/find)
- `/services`  — Мои услуги (app/services/page.js)
